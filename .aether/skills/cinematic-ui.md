# Skill — Cinematic UI

Making an interface read as a place rather than a document.

## Layer like a matte painting

Depth comes from a small number of well-ordered planes, each with a distinct job: base colour → far plate → midground → aerial veil → light → subject → near framing → vignette → haze. Two planes make a background. Four to five make a world. Ten make mud.

Each plane needs its **own artwork or own treatment**. Reusing one plate blurred at two scales reads as a blurred double, never as distance.

## Aerial perspective does the heavy lifting

Distance is mostly a value shift, not a size shift. A gradient veil that lifts and desaturates the far planes creates more depth than parallax does. Parallax should only *confirm* an order the still image already has.

## Light the scene, don't light the elements

One dominant light source that the whole scene sits inside beats per-element glow. If a control needs to be seen, put it where the light is, or place a small motivated veil behind it. Global scrims flatten the world.

## Ceremony has a shape

A crossing is `intent → acceleration → threshold → settle → arrival`. Each beat needs a distinct duration and its own reason to exist, and the consequence (the route change) fires **after** the ceremony settles, never during the crossing. A ceremony that can be interrupted must be abortable, and re-entry must abort the previous run.

## Copy is part of the scene

Interface words break immersion faster than pixels. *Arrive*, *cross*, *path*, *destination*, *presence* — not *results*, *browse*, *items*, *cards*. An eyebrow that reads as a location marker does more for the feeling than another gradient.

## Restraint

Every cinematic technique is subtractive. The version that feels most like a world is almost always the one with fewer, quieter, better-placed elements.
